JSON 일괄 등록

정제된 개체 JSON 파일과 이미지 폴더를 선택하면, 기존 등록 파이프라인(원본 업로드 → 워터마크 합성 → 썸네일 생성)과 동일한 방식으로 개체를 등록해요. 이미지 파일명 끝의 숫자가 JSON의 char_number와 자릿수까지 정확히 일치해야 자동으로 매칭돼요(예: 0028 또는 002).

폴더 전체를 선택해도 JSON에 있는 char_number와 매칭되는 파일만 사용돼요. 나머지 파일은 무시되고 업로드되지 않아요.
